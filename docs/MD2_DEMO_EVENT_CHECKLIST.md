# 뮤즈대시 2 시연 행사 관찰 체크리스트

행사: 2026-12-05 무렵, 경기도 (날짜·장소는 다시 확인할 것). 출시(2026-12-25 예정 — 비공식 보도, 미확정) 전에 실물을 볼 수 있는 유일한 기회입니다.

**목적은 하나입니다: 출시일에 무엇부터 할지 정하는 것.** 특히 "움직이는 앨범 커버가 Live2D인가 Spine인가"를 가리는 게 가장 중요합니다.
여기서 본 것은 전부 **시연판 기준**입니다. 출시판에서 달라질 수 있으니, 문서에 옮길 때도 "시연판 기준"으로 표시하고 출시판이 나오면 다시 확인합니다.

휴대폰으로 보기 좋게 짧게 썼습니다. 다 못 봐도 괜찮습니다. **★ 표시만 보면 충분합니다.**

---

## 0. 도착하면 먼저

- [ ] ★ **기기 종류**: PC / 아케이드 기기 / 콘솔(스위치 등) / 모바일 중 무엇인가
      → 아케이드나 콘솔이면 Steam판과 다른 빌드일 수 있습니다. 아래 결과를 "참고"로만 씁니다.
- [ ] **입력 방식**: 키보드 / 버튼 / 터치스크린 / 컨트롤러
- [ ] **버전 표기**: 타이틀 화면이나 설정 화면 구석에 버전 번호가 있는지 (있으면 사진)
- [ ] **촬영이 허용되는지** 먼저 확인. 허용되면 아래 ★ 항목은 영상으로 찍어 두면 나중에 다시 볼 수 있습니다.

> 시연 기기에서는 **보기만** 합니다. 파일을 꺼내거나 프로그램을 설치하거나, 기기 설정을 건드리지 않습니다.

## 1. ★ 앨범 커버: Live2D인가 Spine인가

트레일러에서 살아 움직이는 커버는 확인했습니다. 남은 질문은 **무엇으로 만들었나**입니다.
Live2D면 커스텀 커버 주입이 어렵고(텍스처 교체 정도), Spine이면 1편에서 이미 쓰는 스킨 주입 방식이 그대로 통할 가능성이 큽니다.

- [ ] ★ **시작 로고·크레딧에 Live2D 표기가 있는가**
      Live2D를 쓴 게임은 보통 시작 로고나 크레딧에 Live2D 표기를 넣습니다. **가장 확실한 단서**입니다.
      시작 화면 로고를 끝까지 보고, 크레딧 메뉴가 있으면 열어 봅니다. Spine 표기도 같이 찾습니다.
- [ ] ★ **커서·손가락에 반응하는가**
      PC면 커버 위로 마우스를 움직여 보고, 터치스크린이면 커버를 눌러 봅니다.
      캐릭터가 그쪽으로 고개나 눈을 돌리면 Live2D 쪽으로 기웁니다(Spine도 할 수는 있지만 드뭅니다).
- [ ] **반복이 매번 똑같은가**
      커버를 몇 바퀴 지켜봅니다. 매번 완전히 같으면 미리 만든 애니메이션입니다.
      곡을 빠르게 넘기다 멈췄을 때 머리카락·리본이 관성으로 흔들리는 모양이 매번 다르면 실시간 물리입니다.
      (이것만으로 확정은 못 합니다. 참고용.)
- [ ] **모든 커버가 움직이는가, 일부만인가**
- [ ] **어디서 움직이는가**: 곡 선택 / 앨범 목록 / 결과 화면 / 로딩 화면 중 어디
      → 커스텀 커버를 바꿔 끼울 자리가 몇 곳인지가 여기서 정해집니다.

## 2. 플레이 규칙 (1편 모드 이식에 바로 쓰임)

- [ ] ★ **레인**: 1편처럼 위(공중)·아래(지상) 2레인인가
- [ ] ★ **난이도 개수와 이름**: 1편처럼 3개 + 숨은 난이도인가, 4개 이상인가
      숨은 난이도를 여는 동작이 있는지(1편은 특정 조작으로 열림)도 보면 좋습니다.
- [ ] ★ **판정 이름**: Perfect / Great / Miss 등 화면에 뜨는 글자 그대로
- [ ] **홀드 노트**: 꼬리 끝에서 떼야 하는지, 끝까지 누르고만 있으면 되는지
- [ ] **노트 종류**: 1편에 없던 새 노트가 있는지 (있으면 모양 기억 또는 사진)
- [ ] **보스**: 곡 중간에 보스가 나오는지
- [ ] **노트 속도 변화**: 같은 곡 안에서 노트가 빨라졌다 느려졌다 하는지
- [ ] **설정 메뉴**: 오프셋(지연 보정)·노트 속도·판정 표시 옵션이 있는지

---

## 3. 메뉴 구조

- [ ] **앨범·태그 화면**: 1편처럼 위에 태그(카테고리) 탭이 줄지어 있는지, 구조가 완전히 다른지
      → 1편 태그 아이콘 교체 패치가 가장 깨지기 쉬운 곳입니다(재타깃팅 지도 🔴).
- [ ] **시연판 곡 수** (대략)
- [ ] **캐릭터·엘핀 선택**: 1편처럼 둘을 따로 고르는지
- [ ] **결과 화면**: 등급·점수·정확도 표시 위치
- [ ] **성적 카드·스티커 꾸미기 기능**이 있는지 (1편 `PnlAchCard` 같은 것)
- [ ] **온라인 요소**: 로그인·랭킹·서버 연결 표시가 있는지

## 4. 기기별 추가로 볼 것

**PC라면**
- [ ] 창 제목, 해상도·전체화면 설정 항목
- [ ] 키 설정 화면이 있는지
- [ ] 시작할 때 Unity 로고가 나오는지

**아케이드 기기라면**
- [ ] 버튼 배치(몇 개, 어디에)와 터치스크린 여부
- [ ] 화면 비율(가로로 긴지)
- [ ] 아케이드판은 PC판과 메뉴·입력 코드가 다를 수 있으니, 2·3장 결과는 "참고"로만 적습니다.

## 6. 다녀온 뒤

1. 위 표를 대충이라도 채워서 Claude 세션에 말해 주거나 사진을 넘깁니다.
2. 확인된 것은 [MD2_LAUNCH_CHECKLIST.md](MD2_LAUNCH_CHECKLIST.md) 맨 아래 **실측 기록** 표와
   1편 저장소의 `MUSE_DASH_2_SPECULATIVE_GUIDE.md`(Live2D 경고 칸)에 **"시연판 기준"**으로 표시해 반영합니다.
3. Live2D 판정에 따라 출시일 순서를 정합니다.
   - **Live2D 표기 있음** → 출시일 정찰(체크리스트 3장)에서 `Live2DCubismCore.dll`과 `Live2D.Cubism.*` 어셈블리를 찾고, 덤프 대상에 추가합니다. 커버는 텍스처 교체부터 시도합니다.
   - **Live2D 표기 없음** → 움직이는 커버는 Spine일 가능성이 큽니다. 1편 Spine 스킨 주입을 커버까지 넓히는 쪽으로 갑니다.
   - **판단 못 함** → 출시일 파일 확인으로 넘깁니다(10분이면 됩니다).
